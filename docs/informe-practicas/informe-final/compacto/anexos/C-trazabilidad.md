# Anexo C. Matriz de trazabilidad de pruebas

La matriz vincula cada historia de usuario con las pruebas que la cubren (servidor, cliente, aceptación manual y recorridos de extremo a extremo) e identifica los huecos de cobertura. Es el documento de verificación de las historias del proyecto; las cifras de pruebas del Capítulo VI corresponden al commit indicado allí, y la matriz describe la cobertura funcional.
