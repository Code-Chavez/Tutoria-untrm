# Instrucciones para Claude Code — Tutoria-untrm

## Issues y pruebas

Antes de modificar código, busca el issue relacionado en `Code-Chavez/Tutoria-untrm` y lee sus criterios de aceptación. Si falta y el trabajo es una tarea del proyecto, crea uno después de comprobar que no hay duplicados. Sigue el flujo de la skill `issues-playwright` (`/issues-playwright`): tomar el issue, comprobar criterios, probar con Playwright en un entorno aislado cuando el cambio afecte recorridos de usuario, vincular el PR con `Relacionado con #N` y registrar la evidencia en el issue.
